BabaYaga Child Theme (for Hello Elementor)
==========================================

Created for:
- Site: https://tavern101agoura.launchpreview.live/
- Developer: devBaba

Installation
------------
1. Zip the `babaYaga` folder (already prepared if you use `babaYaga.zip` from this workspace).
2. In WordPress admin, go to Appearance > Themes > Add New > Upload Theme.
3. Upload and install the zip.
4. Activate "BabaYaga Child".

Requirements
------------
- Parent theme must be installed:
  hello-elementor

Customization
-------------
- Add CSS in `style.css`.
- Add custom PHP hooks/filters in `functions.php`.
